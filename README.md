## 🛠️ Prerequisites

- Java JDK 8 or above
- IDE: IntelliJ IDEA / Eclipse / VS Code
- For JDBC: MySQL or any compatible RDBMS + JDBC driver
- For JavaFX: JavaFX SDK

## 🚀 Running a Program

```bash
# Compile
javac Basics/HelloWorld.java

# Run
java -cp Basics HelloWorld
```
